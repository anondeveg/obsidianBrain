# NOTE:
GENERATED ALWAYS: Prevents users from accidentally inserting manual values into the ID column, protecting your sequential logic.

GENERATED BY DEFAULT: If you want to allow overriding the system sequence with manual IDs (e.g., during database migrations), replace ALWAYS with BY DEFAULT
