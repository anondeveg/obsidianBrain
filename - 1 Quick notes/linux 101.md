- **1991:** Linus Torvalds starts Linux as a free Unix-like OS for PCs.
-
- 15K developers Completely Opensource!
		- [Kernel](https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/tree/)


- **Roots:** Inspired by Unix; aimed to be free and open-source.
	- Unix
		- **1969:** Unix developed at AT&T Bell Labs by Ken Thompson, Dennis Ritchie, and others.
    
		- **Design:** Simple, modular, and portable; emphasizes text-based tools and scripts.
    
		- **File system:** Everything is treated as a file (including devices).

    
- **First kernel:** Version 0.01 could barely run, but others joined to improve it.
    
- **GNU connection:** Combined with GNU tools to form a full OS (GNU/Linux).
	    - https://en.wikipedia.org/wiki/GNU
    
- **1990s:** Linux distributions (Slackware, Debian, Red Hat) make it user-friendly.
    
- **2000s:** Adopted in servers, supercomputers, and embedded systems.
    
- **Android:** Mobile OS based on Linux powers billions of devices.
    
- **Today:** Dominates servers, cloud, and embedded systems; desktops growing.
