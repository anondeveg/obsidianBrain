# Design docs 

Design docs are the first step toward building said system. a design doc is a pre-code written document that specifies all the details about the project to be made. the purpose of this document is to define high-level implementation strategies, architecture,trade-offs before committing to actual code. It helps us solve problems early in the project life-cycle, and becomes a shareable artifact for engineers to read and discuss.
