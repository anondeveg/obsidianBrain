## CLR 
   clr stands for claim level relaibilty assasment
   what it does is that it generates multiple paths for the same input
   then assesess each output gives it a score and chose the highest score as the final answer.
   this approach is ran at inference time making the model slower but raising the accuracy of it  
   about 4.4 percentage points in IMO-AnswerBenchScore from 76.4 to 80.6
   
Supervised fine-tuning(SFT) is mentioned as the process where:
	 a pretrained model is fine-tuned using input-to-output dataset

RL stage (Reinforcment-learning):
	is the stage where a model learns by 
		-trial
		- error
		- rewards
