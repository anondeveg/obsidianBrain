
**objects are data abstractions** that captures and **internal representation** through data
attributes

an interface for interacting with an _object_ through *methods (functions)* 
	an interface defines behavior, but hides implementation

for example having a class **Car**
	the internal representation (AKA data)
	 might be:
	 - height of the car
	 - number of wheels
	 - color 
	 - number of doors

and the methods might be:
	- open window()
	- open door
	- ride
