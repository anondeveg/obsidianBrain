## handeling errors gracefully
-1 immediate error response
	recoverable errors, if sending emails failed retry with [[exponentioal backoff]]
-2  containment and graceful degredation
		- providing backup/ cached content.


error recovery strategies:
	- backups 
	- data-integrity etc
	- error propogation control 

## global error handeling

make a global error handeling middleware
this middleware is the only part of the code that handles errors 
everything else bubbles the error up to it.

now make Error types throughout the application
then bubble the error to the middleware and handle it there
(switch case most probably).



## Security
DO NOT LEAK DETAILS IN ERRORS !!
do not throw errors as is.

DO NOT LEAK userdata IN LOGS!

log userid instead of email etc etc.
